# 뽀린걸 팬사이트

정적 HTML/CSS/JS로 만든 비공식 팬사이트 초안입니다.

## 포함 기능
- 반응형 모바일/PC 레이아웃
- 프로필/콘텐츠/방송/공식 링크 섹션
- SOOP 공식 채널 링크
- 팬 응원 메모 localStorage 저장
- 외부 링크 새 탭 열기
- 개인정보·사생활 추측을 배제한 팬사이트 원칙

## 실행
`index.html`을 브라우저로 열면 바로 실행됩니다.
인터넷 연결이 있으면 Google Fonts를 불러옵니다. 폰트가 없어도 시스템 폰트로 동작합니다.

## 조사 메모
- SOOP 공개 채널: https://play.sooplive.com/bboringirl
- 공개 소개 자료에서는 뽀린걸을 SOOP에서 활동하는 버추얼 스트리머로 소개하며, 소통/게임/버추얼 콘텐츠가 주요 활동으로 확인됩니다.
- 팬사이트는 비공식 사이트임을 명시했습니다.
- 인물의 민감하거나 사적인 정보는 사이트 콘텐츠에서 제외했습니다.

## 배포
GitHub Pages, Cloudflare Pages, Netlify 등 정적 호스팅에 `index.html`, `style.css`, `script.js`를 올리면 됩니다.
